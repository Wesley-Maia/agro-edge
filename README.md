# AgroEdge 🌱🧠

Plataforma modular de Agricultura Inteligente baseada em Edge Computing.

Sistema completo para monitoramento, automação e análise de pequenas propriedades rurais, inspirado no modelo da Embrapa, porém evoluído para uma arquitetura tecnológica distribuída com ESP32 + Raspberry Pi.
